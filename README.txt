사카츠쿠 한글패치 - Windows 폴더형 게임용

1. 원본 게임을 직접 준비하고 RPCS3를 완전히 종료하세요.
2. 배포 압축파일 전체를 풀고 RUN_PATCH.cmd를 실행하세요.
3. PS3_GAME이 들어 있는 게임 폴더를 선택하세요.
4. PATCH COMPLETE / SUCCESS가 나오면 RPCS3에서 실행하세요.

ISO 파일에 직접 적용하는 패치가 아닙니다. 폴더형 게임에 사용합니다.
Python, xdelta, 별도 설치 프로그램은 필요하지 않습니다.
Windows PowerShell을 사용하며 실행 시 창을 닫지 마세요.

원본 SHA-256과 일치하는 파일에만 적용합니다. 다른 버전이나 기존의
다른 한글패치가 있으면 중단합니다. 이미 이 패치와 동일한 파일은 건너뜁니다.
모든 파일의 변환 결과를 검사한 다음 원본 백업과 적용을 시작합니다.
백업 위치: PS3_GAME/USRDIR/KoreanPatch_Backup_고유번호
복구하려면 에뮬을 종료하고 백업 폴더 내용물을 USRDIR/data에 덮어쓰세요.
세이브데이터는 수정하지 않습니다. 기존 세이브에 저장된 이름은 그대로일 수 있습니다.

이 패치는 현재 검수본의 번역·폰트를 포함합니다. 모든 화면의 번역과 표시가
완벽함을 보장하지 않으며, 실제 게임에서 발견한 오역은 추후 수정 대상입니다.
원본 게임, 에뮬레이터, 세이브는 포함되어 있지 않습니다.

명령줄 검사(게임 파일 변경 없음):
powershell.exe -NoProfile -ExecutionPolicy Bypass -File patcher.ps1 -GamePath "게임폴더" -Mode Verify

패치 형식: SHA-256으로 원본을 확인하는 압축 XOR 차이 데이터.
배포 시 PATCH 폴더 안의 파일을 모두 함께 배포하세요.
