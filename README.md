# 프로축구클럽을 만들자! 2013 (PS3) 비공식 한국어 패치

**프로축구클럽을 만들자! (Sakatsuku 2013, PS3)** 게임을 한국어로 플레이할 수 있는 원클릭 자동 패치 도구입니다.  
RPCS3 에뮬레이터에서 실행 가능한 폴더형 게임을 대상으로 제작되었습니다.

---

## 📌 주요 특징

- **단일 실행 파일(`.exe`) 제공**: 별도의 프로그램 설치나 압축 해제 없이 `Sakatsuku_Korean_Patch.exe` 하나로 즉시 실행 가능합니다.
- **원클릭 자동 패치**: 직관적인 GUI 화면에서 게임 폴더를 선택하고 [패치 적용하기] 버튼만 누르면 1초 만에 완료됩니다.
- **안전한 무결성 검증**: 원본 파일의 SHA-256 해시를 엄격히 검증하여 변조되지 않은 원본에만 정확하게 패치합니다.
- **자동 원본 백업 & 롤백**: 패치 전 원본 파일을 자동 백업하므로 언제든 원상 복구가 가능합니다.
- **스크립트 방식도 동시 지원**: 오픈소스 투명성을 위해 PowerShell(`patcher.ps1`) 및 C# 소스 코드(`src/`)도 함께 제공됩니다.

## 🎮 설치 및 적용 방법

### 방법 1. 단일 실행 파일 사용 (가장 간편한 방법)
1. **RPCS3 종료**: RPCS3 에뮬레이터가 실행 중이라면 완전히 종료합니다.
2. **실행**: `Sakatsuku_Korean_Patch.exe`를 실행합니다.
   > 💡 **SmartScreen 알림이 뜨는 경우**: 개인 제작 오픈소스 파일이므로 "Windows의 PC 보호" 파란 창이 뜰 수 있습니다. **[추가 정보] → [실행]**을 누르시면 정상 실행됩니다.
3. **폴더 선택**: [찾아보기...] 버튼을 눌러 `PS3_GAME` 폴더가 들어있는 사카츠쿠 게임 폴더를 선택합니다.
4. **패치 적용**: [한글패치 적용하기] 버튼을 누르면 무결성 검사, 원본 백업, 패치가 순식간에 완료됩니다.
5. **완료**: "패치가 성공적으로 완료되었습니다!" 알림창이 뜨면 RPCS3를 켜고 한국어로 게임을 즐기세요!

### 방법 2. 스크립트 방식 사용 (`RUN_PATCH.cmd`)
1. 압축 파일(`Sakatsuku_Korean_Patch.zip`)을 풀고 `RUN_PATCH.cmd`를 실행합니다.
2. 폴더 선택 창이 뜨면 게임 폴더를 선택합니다.
3. `SUCCESS` 메시지가 나오면 완료입니다.

## 🔄 원본 복구 (롤백) 방법

- 패치 적용 시 원본 파일들이 자동으로 다음 경로에 백업됩니다:
  - `PS3_GAME/USRDIR/KoreanPatch_Backup_[고유번호]/`
- 원본 상태로 되돌리려면:
  1. RPCS3를 종료합니다.
  2. 위 백업 폴더 안의 내용물을 `PS3_GAME/USRDIR/data/` 폴더에 덮어쓰기 복사합니다.

## ⚠️ 주의사항

- **폴더형 게임 전용**: ISO 단일 이미지에는 직접 적용되지 않습니다. 폴더 형태로 추출된 게임에 적용해주세요.
- **세이브 데이터 안내**: 세이브데이터 파일은 변경하지 않으므로, 기존 세이브에 저장된 영문/일문 선수명 등은 그대로 유지될 수 있습니다.
- **저작권 안내**: 본 패치는 원작 게임 본편 롬, 에뮬레이터 등을 포함하지 않으며, 순수 사용자 번역 데이터 및 패치 스크립트로만 구성되어 있습니다.
