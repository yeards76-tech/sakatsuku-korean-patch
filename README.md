# 사커 클럽을 만들자! 2013 (PS3) 비공식 한국어 패치

**프로축구클럽을 만들자! (Sakatsuku 2013, PS3)** 게임을 한국어로 플레이할 수 있는 원클릭 패치입니다.  
RPCS3 에뮬레이터에서 실행 가능한 폴더형 게임을 대상으로 제작되었습니다.

---

## 📌 주요 특징

- **원클릭 자동 패치**: 별도의 Python, xdelta 설치 없이 `RUN_PATCH.cmd` 실행만으로 적용 가능합니다.
- **안전한 무결성 검증**: 원본 파일의 SHA-256 해시를 검증하여 변조되지 않은 원본에만 정확히 패치합니다.
- **자동 원본 백업**: 패치 적용 전 원본 파일을 안전한 위치에 자동 백업하므로 언제든 원상 복구가 가능합니다.
- **가벼운 차분 패치**: 저용량 XOR 차분 데이터(`korean.patch`) 방식으로 빠른 패치 속도를 제공합니다.

## 🎮 설치 및 적용 방법

1. **게임 및 RPCS3 종료**
   - RPCS3 에뮬레이터가 실행 중이라면 완전히 종료하세요.

2. **압축 해제**
   - 다운로드받은 `Sakatsuku_Korean_Patch.zip` 파일의 압축을 원하는 폴더에 풉니다.
   - 압축을 풀면 다음 파일들이 있어야 합니다:
     - `RUN_PATCH.cmd`
     - `patcher.ps1`
     - `korean.patch`
     - `README.txt`

3. **패치 실행**
   - `RUN_PATCH.cmd`를 더블 클릭하여 실행합니다.
   - 파란색 또는 검은색 PowerShell 창과 함께 **폴더 선택 창**이 열립니다.

4. **게임 폴더 선택**
   - `PS3_GAME` 폴더가 들어있는 사카츠쿠 게임 폴더(또는 `USRDIR/data` 폴더)를 선택합니다.

5. **완료 및 게임 실행**
   - 패치 작업이 진행되며 검증 및 적용이 완료되면 `PATCH COMPLETE` 및 `SUCCESS` 메시지가 표시됩니다.
   - 키를 눌러 창을 닫고 RPCS3에서 게임을 실행하여 한국어 출력을 확인합니다.

---

## 🔄 원본 복구 (롤백) 방법

- 패치 적용 시 원본 파일들이 자동으로 다음 경로에 백업됩니다:
  - `PS3_GAME/USRDIR/KoreanPatch_Backup_[고유번호]/`
- 원본 상태로 되돌리려면:
  1. RPCS3를 종료합니다.
  2. 위 백업 폴더 안의 내용물을 `PS3_GAME/USRDIR/data/` 폴더에 덮어쓰기 복사합니다.

---

## ⚠️ 주의사항

- **폴더형 게임 전용**: ISO 단일 파일에는 직접 적용되지 않습니다. 반드시 폴더 형태로 추출된 게임에 적용해주세요.
- **세이브 데이터 안내**: 세이브데이터 파일은 변경하지 않으므로, 기존 세이브에 저장된 영문/일문 선수명 등은 그대로 유지될 수 있습니다.
- **저작권 안내**: 본 패치는 원작 게임 본편 롬, 에뮬레이터 등을 포함하지 않으며, 순수 사용자 번역 데이터 및 스크립트로만 구성되어 있습니다.
