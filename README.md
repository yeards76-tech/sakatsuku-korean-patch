# 사카츠쿠 2013 (PS3) 한국어 패치 0.8

대사, 메뉴, 한글 폰트와 일반 설명 이미지·한글 제목 로고를 함께 적용하는 패처입니다. 게임에서 표시가 깨지던 조각 이미지 모음은 일본어 원본을 유지합니다.

## 다운로드

[0.8 배포 페이지](https://github.com/yeards76-tech/sakatsuku-korean-patch/releases/tag/v0.8)에서 `Sakatsuku_Korean_Patch_v0.8.exe` 또는 `Sakatsuku_Korean_Patch_v0.8_final.zip`을 받으세요. 실행 파일에 패치 데이터가 내장되어 있습니다. ZIP 안의 실행 파일 이름은 `Sakatsuku_Korean_Patch.exe`입니다.

## 적용 방법

1. RPCS3를 완전히 종료합니다.
2. `Sakatsuku_Korean_Patch.exe`를 실행합니다.
3. `PS3_GAME`이 들어 있는 게임 폴더를 선택하고 적용 버튼을 누릅니다.
4. 완료 메시지를 확인한 뒤 게임을 실행합니다.

일본판 BLJM61064 폴더형 게임용입니다. ISO 파일에 직접 적용하지 않습니다. 원본, 이전 공식 패치와 앞서 공개한 0.8 배포본에서 갱신할 수 있습니다. 현재 최종본과 같은 파일은 건너뜁니다. 지원하지 않는 수정본은 모든 파일을 검사한 뒤 적용 전에 중단합니다.

RPCS3 폴더 아래 게임을 선택하면 같은 에뮬레이터의 BLJM61064 설치 데이터와 업데이트 데이터에 이미 존재하는 대응 파일도 함께 갱신합니다. 세이브 데이터는 변경하지 않습니다.

## 0.8 변경 사항

- 일반 설명 이미지 56개, 한글 제목 로고, 주의문, 감독 생성 화면, 경기 지시 배너 42종, 비서 선택 배경 2개, 전술 키워드 설정 1개를 포함(총 104개).
- DDS 변환을 Microsoft DirectXTex BC3 인코더로 통일해 녹색 글씨의 획이 뭉개지던 현상을 개선. 튜토리얼 49장의 제목과 본문을 맑은 고딕 굵은 글꼴과 자연스러운 자간으로 정리하고 이미 같은 스타일인 7장은 유지.
- 튜토리얼 예시 화면 안에서 겹치던 작은 글씨는 원본으로 복원하고, 바깥 한글 설명은 유지. 작은 예시 화면 안에는 일본어가 남을 수 있습니다.
- 비서 배경은 이름과 혈액형·출신지·생일·신장·취미만 한글화. 긴 소개문, 캐릭터 모음, 호칭과 작은 메뉴 조각은 원본을 유지.
- 게임과 호환되지 않던 겹치는 복사 명령을 제거한 SLLZ 압축을 사용. 이미지 아카이브의 원본 크기와 배치 위치를 유지하고, 수정한 각 압축 데이터도 원본 이하 크기로 제한.
- 입장 인사에서 ‘무례합니다’로 나오던 문구를 ‘실례합니다’로 수정하고, 상황에 따라 퇴장 인사를 조정.
- 대사·설명 507개 문구를 검토해 반복 항목 784곳 수정. 감사 인사, 연계, 치료, 루즈볼 등 오역과 일부 프로필 문장 정리.
- 추가로 임대 이적과 오퍼 용어 159곳 수정. ‘마감된 이적’ 등을 ‘임대 이적’으로, ‘쿠폰’을 ‘오퍼’로 통일.
- 크기가 달라진 리소스와 이전 배포본 업그레이드를 지원하는 패처로 변경.

전체 번역을 사람이 한 문장씩 최종 검수했다는 의미는 아닙니다. 남은 오역이나 실제 게임에서의 표시 문제는 화면과 함께 제보해주세요.

검증: 원본 및 이전 배포본 적용, 백업 해시, 재적용, 지원하지 않는 버전의 적용 전 중단을 확인했습니다. 모든 수정 이미지의 압축 해제 결과·원본 배치·용량 제한을 검증했습니다. 튜토리얼·비서 화면·전술 키워드 설정의 정상 표시를 사용자에게 확인받았습니다. 모든 이미지의 모든 장면을 게임에서 확인한 상태는 아닙니다.

## 백업과 복구

변경 파일은 각 `data` 폴더의 상위 폴더에 생성되는 `KoreanPatch_Backup_v0.8_...`에 백업됩니다. 적용 후 파일 검증이 실패하면 이번 적용분을 자동 복원합니다. 수동 복구는 RPCS3를 종료한 뒤 백업 내용물을 대응하는 `data` 폴더에 복사하세요. 이전 패치에서 업그레이드한 경우 백업도 이전 패치 상태입니다.

## 스크립트 및 소스

ZIP의 `RUN_PATCH.cmd`와 `patcher.ps1`은 동일한 실행 파일을 호출합니다. `patcher.ps1 -GamePath "게임 폴더" -Mode Verify`는 저장 없이 적용 가능 여부만 검사합니다. C# 소스와 빌드 명령도 ZIP에 포함합니다. 배포 파일의 SHA-256은 `SHA256SUMS.txt`로 확인할 수 있습니다.

게임 본편과 에뮬레이터는 포함하지 않습니다. 패치 데이터는 원본에 적용하는 차분입니다.

현재 최종 실행 파일과 이미지 차분은 위 배포 페이지에서 받으세요. 저장소 루트의 이전 바이너리는 최종본이 아닙니다. GitHub 자동 Source code 압축 대신 배포 페이지의 final_source.zip을 사용하세요.
