# 사카츠쿠 2013 (PS3) 한국어 패치 0.9

대사·메뉴·한글 폰트와 0.8의 이미지 수정을 포함한 누적 패치입니다. 일본판 BLJM61064 폴더형 게임용이며 게임 본편과 에뮬레이터는 포함하지 않습니다.

## 다운로드

[0.9 배포 페이지](https://github.com/yeards76-tech/sakatsuku-korean-patch/releases/tag/v0.9)에서 `Sakatsuku_Korean_Patch_v0.9.exe` 또는 `Sakatsuku_Korean_Patch_v0.9.zip`을 받으세요. 실행 파일에는 패치 데이터가 내장되어 있습니다. ZIP 내부 실행 파일 이름은 `Sakatsuku_Korean_Patch.exe`입니다.

저장소 루트의 이전 바이너리 대신 위 배포 파일을 사용하세요. GitHub가 자동 생성하는 Source code 압축과 별도로 배포한 `Sakatsuku_Korean_Patch_v0.9_source.zip`은 내용이 다릅니다.

## 적용 방법

1. RPCS3를 완전히 종료합니다.
2. 패처를 실행하고 `PS3_GAME`이 들어 있는 게임 폴더를 선택합니다.
3. 적용 완료 메시지를 확인한 뒤 게임을 실행합니다.

원본과 0.8에서 바로 0.9로 업데이트할 수 있습니다. 기존 0.8 초기·중간 배포본의 지원 해시도 유지했습니다. 이미 0.9와 같은 파일은 건너뛰며, 지원하지 않는 파일은 쓰기 전에 검사를 중단합니다. ISO에 직접 적용하지 않습니다.

선택한 게임이 RPCS3 폴더 아래 있으면 같은 에뮬레이터의 BLJM61064 설치 데이터와 업데이트 데이터에 이미 있는 대응 파일도 함께 갱신합니다. 세이브 파일은 변경하지 않습니다.

## 0.9 변경 사항

- 대사·이벤트 후보 13,020종을 분류하고, 기존 검수 결과와 함께 남은 구간의 원문·인접 항목·성격별 말투를 대조했습니다.
- 누적 대사 5,769종, 실제 수록 위치 8,752곳의 오역·번역투·어색한 구어체를 수정했습니다. 승패, 은퇴, 부상 회복, 협상, 인터뷰와 유망주 소개 등의 문맥을 정리했습니다.
- 선수명·구단명·호칭·금액·순위·기간 등이 빠지거나 문장 중간에 잘못 들어가던 문제를 수정하고, 누적 동적 입력 칸 4,025개를 검증했습니다.
- 감독 호칭과 일부 축구 용어를 정리했습니다. 원문 자체가 불완전한 내부 문구 2종은 추측하지 않고 보존했습니다.
- 0.8의 한글 폰트, 설명 이미지와 제목 로고, SLLZ 호환성 및 글씨 가독성 개선을 포함합니다. 이번 버전에서는 기존 이미지 데이터를 다시 변환하지 않았습니다.

## 검증 범위

원본 적용, 0.8 업그레이드, 이미 검수본이 적용된 데이터의 무변경 처리, 적용 전 검사, 백업 해시, 적용 후 전체 파일 해시, 재적용, 알 수 없는 버전의 쓰기 전 거부를 복사본에서 검사했습니다. 패치 대상은 191종 리소스입니다. 대사 구조·ID·입력 칸·제어 명령·한글 글리프 검사와 실제 RPCS3 기동 확인도 수행했습니다.

모든 분기를 실제로 플레이하거나 모든 수정 대사를 화면에서 확인한 것은 아닙니다. 일부 작은 메뉴 조각, 튜토리얼 예시 내부 화면 등에는 일본어가 남을 수 있습니다. 이상한 문장이나 표시 문제가 있으면 해당 장면을 제보해주세요.

## 백업과 복구

각 `data` 폴더의 상위 폴더에 `KoreanPatch_Backup_v0.9_...` 백업이 생성됩니다. 저장 후 검증이 실패하면 이번 적용분을 자동 복구합니다. 수동 복구는 RPCS3를 종료하고 해당 백업을 대응하는 `data` 폴더에 복사하세요. 0.8에서 업데이트한 경우 백업도 0.8 상태입니다.

## 스크립트와 소스

`RUN_PATCH.cmd`와 `patcher.ps1`은 같은 실행 파일을 호출합니다. `patcher.ps1 -GamePath "게임 폴더" -Mode Verify`로 저장 없이 적용 가능 여부만 검사할 수 있습니다. `src/`와 `build_exe.cmd`는 C# 소스와 빌드 명령입니다. 소스 ZIP으로 재빌드하려면 같은 0.9 릴리스의 `korean.patch`를 받아 소스 ZIP을 푼 폴더에 놓으세요. 전체 ZIP에는 해당 데이터도 들어 있습니다.

배포 파일 무결성은 `SHA256SUMS.txt`로 확인할 수 있습니다.
